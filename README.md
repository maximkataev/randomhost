# Randomhost

- randomhost.online

Одностраничный набор рандомайзеров и мини‑игр для розыгрышей, выбора победителей и вечеринок. Все страницы — статические HTML с кастомным дизайном (стекло, градиенты, анимация звёзд/частиц) и работают без сборки.

## Что внутри
- Главная `index.html` — витрина со всеми карточками и мини‑играми.
- Игры для выбора участника: гонки, колесо фортуны, бинго, банк (🇲🇽), плинко, лототрон, магический шар, трейдинг, турнир.
- Социальные/вечеринка: рандомный вопрос, карты Таро, «что бы ты выбрал?» (скоро).
- Аркады: «Желешки» (антистресс) и «Не урони!» (`dont-drop.html`) — реакция, жизни, волны, рекорд в localStorage.
- Простые генераторы: случайное число, подброс монетки, выбор строки.
- Мини‑игры в футере: «Мне повезёт» (33.3% шанс) и «Угадай число».

## Быстрый старт
- Способ 1: просто открой `index.html` в браузере.
- Способ 2 (удобно для кросс‑браузерного теста):  
  `python3 -m http.server 8000` и открой `http://localhost:8000/`.

## Структура
- `index.html` — главная витрина + мини‑игры + фоновые эффекты.
- Остальные *.html — отдельные игры/генераторы (см. названия файлов).
- `nginx.conf`, `docker-compose.yml` — простая статическая подача (используется nginx).

## Заметки по фронту
- Декор: фиксированный слой звёзд и плавающих частиц, интеракции hover и появления через Intersection Observer.
- Адаптив: `auto-fit` grid, мобильный режим в медиазапросах `<768px`.
- Аналитика: Yandex.Metrika (`ym(104849796, 'init', …)`).
- Доступность: отключение анимаций через `prefers-reduced-motion`; кнопка «наверх» показываетcя после 300px скролла.
