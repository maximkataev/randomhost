# Randomhost

- randomhost.online

Одностраничный набор рандомайзеров и мини‑игр для розыгрышей, выбора победителей и вечеринок. Все страницы — статические HTML с кастомным дизайном (стекло, градиенты, анимация звёзд/частиц) и работают без сборки.

## Что внутри
- Главная `index.html` — витрина со всеми карточками и мини‑играми.
- Игры для выбора участника: гонки, колесо фортуны, бинго, банк (🇲🇽), плинко, лототрон, магический шар, трейдинг, турнир, утиные бега (`duck-race.html`), пингвины на льдине (`penguin-floe.html`) — схватка на выбывание на раскалывающейся льдине, выборы (`elections.html`) — избиратели идут к урне, лайв-табло, снятие кандидатуры и инаугурация.
- Социальные/вечеринка: рандомный вопрос, карты Таро, «что бы ты выбрал?» (скоро).
- Аркады: «Желешки» (антистресс) и «Не урони!» (`dont-drop.html`) — реакция, жизни, волны, рекорд в localStorage.
- «Терминал Квест» (`terminal-quest.html`) — симулятор bash с 16 офисными заданиями (виртуальная ФС, пайпы, sudo, docker, VPN); ведущий дейлика и виновник берутся из общего списка участников, за rm -rf ругают.
- Простые генераторы: случайное число, подброс монетки, выбор строки.
- «Псевдорандом» (`time-randomizer.html`) — метка времени нажатия делится на число участников, остаток — порядковый номер победителя. Вероятности и список участников общие с остальными играми.
- «Викирандом» (`wiki-random.html`) — слушает живую ленту правок Википедии (ru/en/el, статьи, без ботов), берёт первую правку после нажатия; сумма номеров букв заголовка по модулю числа участников (или 100 при разных шансах) — номер победителя. Лента отключается через 5 минут бездействия и в фоновой вкладке.
- «Биткоин-рандом» (`bitcoin-random.html`) — живой поток неподтверждённых биткоин-транзакций (WebSocket blockchain.info, запасной путь — опрос mempool.space); после нажатия берём первый перевод на кошелёк, которого ещё не было в ленте (частые адреса бирж пропускаются и запоминаются в `btc_hot_addrs_v1`), сумма символов адреса (a=1…z=26, цифра = себе) по модулю числа участников (или 100 при разных шансах) — номер победителя.
- «Радар» (`radar.html`) — индикатор диспетчера с настоящими самолётами вокруг выбранного аэропорта (12 секторов: Франкфурт, Лондон, Нью-Йорк…; Москвы нет — сети ADS-B её не видят) (ADS-B от adsb.fi, запасной adsb.lol). После нажатия сервис `sky/` делает новый снимок неба; из самолётов в полёте (свежие координаты, ≥60 kt) берётся ближайший к центру, последние 4 цифры его широты по модулю числа участников (или последние 2 при разных шансах) — номер победителя. Браузер ходит только в `/sky/api/` (nginx → контейнер `sky`, Node без зависимостей, опрос источника раз в 4 с и только пока страницу кто-то смотрит; тесты — `node sky/test.js`).
- Мини‑игры в футере: «Мне повезёт» (33.3% шанс) и «Угадай число».

## Быстрый старт
- Способ 1: просто открой `index.html` в браузере.
- Способ 2 (удобно для кросс‑браузерного теста):  
  `python3 -m http.server 8000` и открой `http://localhost:8000/`.

## Структура
- `index.html` — главная витрина + мини‑игры + фоновые эффекты.
- Остальные *.html — отдельные игры/генераторы (см. названия файлов).
- `nginx.conf`, `docker-compose.yml` — простая статическая подача (используется nginx).

## Заметки по фронту
- Декор: фиксированный слой звёзд и плавающих частиц, интеракции hover и появления через Intersection Observer.
- Адаптив: `auto-fit` grid, мобильный режим в медиазапросах `<768px`.
- Аналитика: Yandex.Metrika (`ym(104849796, 'init', …)`).
- Доступность: отключение анимаций через `prefers-reduced-motion`; кнопка «наверх» показываетcя после 300px скролла.

## Локальная правка
- Всё в одном файле, без сборки. Достаточно редактировать HTML/CSS/JS.
- Фавикон тянется по ссылке: `https://em-content.zobj.net/source/apple/391/sparkles_2728.png`.
## Аукцион (`auction.html`, `auction-board.html`)
Онлайн-игра: хост создаёт комнату на большом экране, игроки заходят по QR с телефонов, торгуются за лоты (артисты, фильмы, блюда… — 15 категорий, ~2000 карточек), в конце составы оценивает ChatGPT (или голосование). Первый бэкенд сайта — `auction/` (Node 22 + `ws`), в compose отдельный сервис `auction`; nginx проксирует в него `/auction/ws` и `/auction/api/`. Ключ OpenAI — в `.env` на сервере (`OPENAI_API_KEY`, `OPENAI_MODEL`), в git не хранится. Спека и ревью — в репозитории random-picker (`docs/SPEC.md`). На главной не публикуется.

- Локально: `cd auction && npm install && npm run dev` → http://localhost:3000/auction.html (боты: кнопка «+ 3 бота» в лобби; `?bots`/ускорение только при `NODE_ENV=development`).
- Симуляция партий: `node auction/sim.js 200 4`.
- `auction-solo.html` — прежний локальный рандомайзер без сервера, данные в `auction-data/`.
