## Известные падения и нестабильность

- **Красных тестов «до» нет.** Заявленный известный красный — lastq `test-content`, дубль `space_nature-103 = science-109` —
  в этом дереве **не воспроизводится**: `lastq/test-content.js` зелёный (6 из 6, ещё 114/114 по `npm test`), в
  `lastq/content/{ru,en,el}.json` нет id `space_nature-103` (есть `science-103`, `science-109`). Судя по памяти, это
  правка банка 11.10, которой нет в этой ветке. Если она появится — `run-all-tests.sh` пометит lastq как
  «RED (известный)» и напишет причину (функция `known_red` в скрипте).
- **auction `test-server.js` изредка мигает под нагрузкой:** в одном из трёх прогонов (полный прогон, пока на машине
  параллельно шли другие стенды; два последующих одиночных — 240 ✓ / 0 ✗, 190–194 с) упали «в торгах все, кроме
  лидера, скипнули — продано лидеру» и «запоздавший скип прошлого лота отклоняется», затем `fetch failed` в `make()`
  (тест оборвался, 177 ✓ / 2 ✗); в повторном одиночном прогоне — 240 ✓ / 0 ✗. Сервер при этом не падал (лог
  чистый). Подозрение: сброс keep-alive-соединения undici между длинными паузами теста (эксплуатационный шум стенда,
  не регресс кода). Перед тем как считать красный auction регрессией — перезапустить `run-all-tests.sh auction`.
- `--parallel` у `run-all-tests.sh` ускоряет, но тайминговые тесты (roulette 18-секундные спины, auction) мигают чаще —
  для baseline/CI использовать последовательный режим (по умолчанию).

## Замечания по окружению

- В каждой игре `ws` лежит в `<игра>/node_modules`; в worktree нужны симлинки
  (`ln -s <основной репо>/<игра>/node_modules <игра>/node_modules`) — каталоги в `.gitignore` как `node_modules/`
  (с косой чертой), симлинк-файл git видит как untracked: не добавлять в коммит.
- Порты: игры в `test-server.js` сами выбирают случайные (5000–5900); auction-стенд — `AUCTION_PORT` или 4000–4899;
  `smoke.js --spawn --port-base N` — N…N+9. У rapids и lastq один порт по умолчанию (3800) — разводить через `PORT`.
