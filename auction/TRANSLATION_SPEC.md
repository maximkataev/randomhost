# Перевод карточек лотов: формат и правила

Карточки — это то, что игроки читают вслух за столом. Перевод должен звучать так, будто
карточку сразу писали на этом языке, а не переводили.

## Куда класть

- Источник: `auction/data/<kind>.json` (русский, не трогать).
- Результат: `auction/data/en/<kind>.json` и `auction/data/el/<kind>.json`.

**Порядок и количество карточек обязаны совпадать с русским файлом ровно.** Сервер сверяет длину и
при расхождении молча берёт русскую колоду: номер карточки в дампе игры привязан к позиции в массиве.
Ничего не добавлять, не удалять, не переставлять.

## Поля

| Поле | Что делать |
|---|---|
| `name` | Настоящее имя на целевом языке. Подробности ниже. |
| `emoji` | Копировать как есть. |
| `meta` | Перевести. Сохранить количество элементов и порядок. |
| `description` | Перевести, 180–350 знаков. |
| `fact` | Перевести, до 200 знаков. |
| `wiki_en`, `wiki_ru` | **Копировать как есть, не переводить и не выдумывать.** Это ключи к Википедии, по ним ищется картинка. Сломанный ключ = карточка без фото. |
| `top_song` | Копировать как есть (название песни не переводится). |
| любое другое | Копировать как есть. |

## Имена

Главное правило: **как эту вещь называют носители языка**, а не транслитерация с русского.

- Английский: `Агата Кристи (группа)` → `Agatha Christie (band)`, `Лунтик` → `Luntik`,
  `Нью-Йорк` → `New York`, `Битлз` → `The Beatles`. Если предмет известен в англоязычном мире под
  своим названием — берём его, а не перевод русского написания.
- Греческий: общепринятое греческое имя, если оно есть (`Νέα Υόρκη`, `Αθήνα`, `Λεονάρντο ντα Βίντσι`).
  Для современных западных групп, брендов и фильмов греки обычно пишут латиницей — так и оставляем
  (`The Beatles`, `Netflix`). Не транслитерировать насильно.
- Блюда: `борщ` → `borscht` / `μπορς`; если блюдо в языке известно под оригинальным именем, оставить его.

Если не уверен в устоявшемся названии — проверь по `wiki_en` (это заголовок статьи в английской
Википедии, он же подсказывает принятое написание).

## Описания и факты

- Сохранять **смысл и фактическую точность**. Это главное: факт про переход у Эбби-Роуд должен
  остаться фактом про переход у Эбби-Роуд.
- Не сохранять синтаксис русского предложения. Переписывать естественно для языка.
- Русские пояснения, нужные только русскому читателю («известна у нас по…»), заменять на то, что
  осмысленно для носителя языка, либо убирать.
- Тон живой и конкретный, без канцелярита и без рекламных восклицаний.
- Кавычки по правилам языка: английский `"…"`, греческий `«…»`.
- Не выдумывать фактов, которых нет в исходнике. Если факт непроверяем или завязан на русский
  контекст — перефразировать ближе к общеизвестному, но **не сочинять новый**.

## Проверка перед сдачей

```
node -e '
const fs=require("fs");
const kind="<kind>", lang="<lang>";
const ru=JSON.parse(fs.readFileSync(`auction/data/${kind}.json`,"utf8"));
const tr=JSON.parse(fs.readFileSync(`auction/data/${lang}/${kind}.json`,"utf8"));
if (ru.length!==tr.length) throw new Error(`длина ${tr.length} против ${ru.length}`);
ru.forEach((r,i)=>{
  const t=tr[i];
  if (r.emoji!==t.emoji) throw new Error(i+": emoji разъехались");
  if ((r.meta||[]).length!==(t.meta||[]).length) throw new Error(i+": длина meta");
  for (const k of ["wiki_en","wiki_ru","top_song"]) if (r[k]!==t[k]) throw new Error(i+": "+k+" изменён");
  if (/[а-яА-ЯёЁ]/.test(JSON.stringify([t.name,t.meta,t.description,t.fact]))) throw new Error(i+": остался русский текст");
});
console.log("ок:", tr.length, "карточек");
'
```

Прогоняй её для каждого сделанного файла и приложи вывод к отчёту.
