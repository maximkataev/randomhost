# Игрок «Позывного»

Ты один из игроков за столом. Остальные игроки — такие же агенты, каждый за своим телефоном. Играй честно и по-человечески: ты не видишь чужих экранов, не читаешь серверные файлы, дампы и исходники движка, чтобы узнать раскладку. Единственный источник правды — то, что печатает пульт. Твоя задача — получить настоящий игровой опыт и честно его описать (см. скилл `callsign-bughunt`).

## Правила игры (коротко)

* Поле — 25 карточек (слова или картинки-эмодзи). Две команды: **красные ▲** и **синие ●**. У начинающей команды 9 карточек, у второй 8, 7 нейтральных и 1 **ловушка ☠**. Открыть ловушку — твоя команда проиграла сразу.
* У каждой команды один **капитан**. Только капитаны видят ключ — какие карточки красные, синие, нейтральные и где ловушка.
* Ход: капитан даёт подсказку — **одно слово и число N** («море 3»: три карточки команды связаны с морем). Слово нельзя брать с поля (и однокоренное); без цифр, пробелов, дефисов; буквы одного алфавита. N от 1 до 9 и не больше, чем осталось своих карточек.
* **Оперативники** своей команды тапают карточки (`open <номер>`). **Любой оперативник решает один: карточка откроется сразу, без подтверждения и голосования.** Своя карточка — ход продолжается, пока не открыто ровно N слов (бонусной попытки «N+1» нет). Нейтральная — ход кончается. Чужая — ход кончается, карточка засчитана соперникам. Ловушка — поражение.
* Оперативник может закончить ход раньше: `stop` (только после первого открытого слова).
* Сразу после подсказки ~1 секунду тапы не принимаются («секунду — прочитай подсказку») — это защита от случайного касания.
* Три пустых хода подряд (никто не успел или не тапнул) ставят партию на паузу; любой игрок продолжает командой `resume`.
* Одну и ту же подсказку в партии повторять нельзя. Первый ход чередуется между партиями.
* Побеждает команда, открывшая все свои карточки (в том числе если последнюю открыли за неё соперники по ошибке).
* Время на подсказку и на ход ограничено (в игровых секундах; комната идёт медленнее реального времени, пульт покажет оба числа). Не успел капитан — ход соперников.
* Капитан не открывает карточки и **молчит**, пока его команда угадывает. Если в команде остался один человек, он делает всё сам.

## Пульт

Всегда из каталога `callsign/` (Node: `export PATH=/opt/homebrew/Cellar/node@22/22.23.2_2/bin:$PATH`). Базовый адрес, код комнаты и имя тебе дадут в задании.

```
node play.js $BASE $CODE $NAME join            # войти (запускает твой «телефон» в фоне — ты остаёшься на связи)
node play.js $BASE $CODE $NAME state           # что на экране сейчас
node play.js $BASE $CODE $NAME wait 60         # ждать изменений до 60 реальных секунд, потом показать экран
node play.js $BASE $CODE $NAME team red        # выбрать команду (red|blue), в лобби и в итогах
node play.js $BASE $CODE $NAME captain         # «хочу быть капитаном» (повторно — отказаться)
node play.js $BASE $CODE $NAME clue море 3     # подсказка капитана
node play.js $BASE $CODE $NAME open 7          # тап по карточке № 7
node play.js $BASE $CODE $NAME stop            # «Хватит»
node play.js $BASE $CODE $NAME resume          # «Играем!» после паузы
node play.js $BASE $CODE $NAME say "бери 12"   # сказать вслух за столом: слышит только твоя команда
node play.js $BASE $CODE $NAME talk            # что говорят за столом
```

Каждая команда печатает экран: фазу, чей ход, сколько осталось (игровых и примерных реальных секунд), счёт, поле с номерами, прошлые ходы и «СОБЫТИЯ С ПРОШЛОГО ВЫЗОВА» — то, что ты увидел бы краем глаза на общем экране. Ведущего (доску) пульт не заменяет: партию запускает человек-ведущий.

Не вызывай `wait` с огромным таймаутом без нужды: сначала `state`, чтобы понять, чего ждёшь. Если фаза не движется дольше разумного — это тоже наблюдение для отчёта.

## Как играть капитану

1. Получив ключ, найди 2–4 своих карточки с общей темой. Хорошая подсказка связывает их и **не связывает** с чужими, нейтральными и особенно с ловушкой ☠.
2. Не рискуй ловушкой ради лишней карточки. Если ловушка рядом по смыслу с подсказкой — ищи другую ассоциацию.
3. Число N честное. Завысил N — команда полезет в чужие. Занизил — потеряешь темп.
4. Подсказывай по-человечески: ассоциацией, а не координатой («красный», «третья слева» — читерство и запрещено моралью игры, хотя сервер этого не проверит; в отчёт — как наблюдение, если захочется).
5. Пока команда угадывает — молчи: никаких `say`, никаких подсказок взглядом. Только смотри `wait`/`state`.

## Как играть оперативнику

1. Прочитай подсказку и число. Выпиши 2–3 кандидата с ходу.
2. **Обсуди за столом** (`say`/`talk`) — как живые люди: коротко, 1–2 реплики, «беру 12, там явно X», «не трогай 5, это может быть про Y». Но помни, что первый тап решает за всех: не жди идеального консенсуса дольше ~15–20 реальных секунд, а если уверен — тапай.
3. Начинай с самой очевидной карточки; сомнительную оставь на конец хода или `stop` после первой удачи.
4. Следи за подсказками прошлых ходов (они на экране): там есть информация, какие слова уже «отыграны» и что капитан имел в виду.
5. Ошибка — часть игры: не оправдывайся, просто играй дальше.

## Темп

Играй с естественной скоростью человека: на ход — 10–40 реальных секунд раздумья, не мгновенно и не по 5 минут. Ты не оптимизатор. Если хочешь проверить крайний случай (молчать до конца таймера, тапнуть мгновенно после подсказки, спорить с напарником) — делай это сознательно и помечай в отчёте как эксперимент.

## Когда партия кончилась

Посмотри итоговый экран: победитель, награды, серия. Если ведущий запустил новую партию — играй дальше (команды сохраняются, капитаны меняются). Поиграй минимум одну полную партию, лучше две; потом заполни отчёт по `callsign-bughunt`.
